# Google Sheet 저장 API 및 공휴일 연결

1. [한국천문연구원_특일 정보](https://www.data.go.kr/data/15012690/openapi.do)에서 활용신청 후 인증키를 발급받습니다.
2. 업무대장 Google Sheet에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 이 폴더의 `Code.gs` 내용을 Apps Script의 `Code.gs`에 붙여 넣고 저장합니다.
4. **프로젝트 설정 → 스크립트 속성 → 스크립트 속성 추가**에서 이름을 `DATA_GO_KR_SERVICE_KEY`, 값을 발급받은 인증키로 설정합니다. 일반 인증키(Decoding)를 권장하며 Encoding 키도 지원합니다. 키를 `config.js`나 Git 저장소에 넣지 않습니다.
5. **배포 → 배포 관리 → 수정 → 새 버전 → 배포**로 기존 웹 앱을 갱신합니다. 처음에는 **새 배포 → 웹 앱**을 선택하고 실행 계정을 본인으로, 액세스 사용자를 사이트 이용 범위에 맞게 설정합니다. 외부 요청 권한이 표시되면 승인합니다.
6. 기존 배포를 수정하면 URL은 유지됩니다. 새 URL이 발급되면 프로젝트 루트 `config.js`의 `apiUrl`에 `/exec` URL을 입력합니다.
7. 변경한 프런트엔드 파일을 GitHub Pages에 배포합니다.

Apps Script가 `getRestDeInfo`를 연도별로 조회하며 `isHoliday=Y`인 날짜만 반환합니다. 결과는 6시간 캐시하므로 공휴일 변경이 반영되기까지 최대 6시간 걸릴 수 있습니다. 대체공휴일과 임시공휴일은 API 제공 데이터를 따릅니다. 기존 업무대장 정책에 따라 5월 1일과 사용자가 등록한 추가 휴일도 계속 제외합니다.

공휴일 조회가 실패해도 업무는 불러옵니다. 화면에 실패 이유를 표시하고 기존 규칙 기반 임시 계산값을 사용합니다. 임시 계산값에는 새로 지정된 휴일이 누락될 수 있습니다. 인증키/활용신청 상태를 수정한 뒤 페이지를 새로고침하면 다시 조회합니다.

확인: 페이지 로딩과 연도 이동 시 공휴일이 작업일에서 제외되는지, 인증키가 없을 때 업무는 유지되고 오류 안내가 나오는지 확인합니다.
